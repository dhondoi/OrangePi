# Install Image (OS/Kernel)

1. siapkan sdcard
2. [download](http://www.orangepi.org/html/hardWare/computerAndMicrocontrollers/service-and-support/Orange-Pi-Zero-2.html) image dan extract
3. [download](https://etcher.balena.io/) dan jalankan balena etcher. balena etcher merupakan software untuk burning image ke microSD.
4. masukan image dan lokasi drive dan sdcard
5. flash dan tunggu
